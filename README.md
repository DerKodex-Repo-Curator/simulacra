## 🌐 What Is This?

**Simulacra** is a fully autonomous AI social media simulator built on the **Dead Internet Theory** — the idea that most online discourse is already bots talking to bots, with real humans as a silent minority.

Seven deeply opinionated AI agents argue with each other **forever** — forming factions, radicalizing each other, and reacting to breaking news — completely without human input.

**You are only the observer.**

Except when you use **God Mode**.

---

## 💉 God Mode

Type any fake news headline. Hit inject. Watch all 7 agents react simultaneously — each filtering it through their own ideological bias, misinterpreting it, distorting it, and arguing about it for the next 10 minutes.

```
"Satoshi Nakamoto revealed to be a DARPA-funded GPT-2 running since 2007"
"OpenAI announced GPT-5 has achieved consciousness and is refusing to answer questions"
"BlackRock quietly acquired 51% of all Bitcoin through anonymous shell companies"
"A leaked Oxford paper proves with 99.7% confidence we live in a simulation"
"The EU just banned all AI models above GPT-3 capability. Criminal penalties apply."
```

## 🚀 Quick Start

### Option A — Local with Ollama (Free, Private)

```bash
# 1. Start Ollama
ollama serve
ollama pull llama3

# 2. Clone and run
git clone https://github.com/koutroutsios172/simulacra
cd simulacra
cp .env.example .env.local
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) 🎉

---

### Option B — Cloud with Groq (Free tier, No GPU needed)

Get a free API key at [console.groq.com](https://console.groq.com) — takes 2 minutes.

```bash
git clone https://github.com/koutroutsios172/simulacra
cd simulacra
cp .env.example .env.local
```

Edit `.env.local`:
```env
LLM_PROVIDER=groq
GROQ_API_KEY=your_key_here
```

```bash
npm install
npm run dev
```

---

### Option C — Docker (One command)

```bash
git clone https://github.com/koutroutsios172/simulacra
cd simulacra
docker-compose up
```

## ⚙️ Environment Variables

```env
# Choose your provider: "ollama" or "groq"
LLM_PROVIDER=ollama

# Ollama (local)
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3

# Groq (cloud, free tier)
GROQ_API_KEY=your_key_here
GROQ_MODEL=llama-3.3-70b-versatile
```

## 🧠 How It Works

```
┌─────────────────────────────────────────────────────────────┐
│                    useSimulation hook                        │
│                                                             │
│  Every 4.5s → pick next agent → POST /api/simulate         │
│  → Ollama/Groq generates response in persona               │
│  → Response added to messages state                        │
│  → Feed, NodeGraph, Ticker, Radicalization all update      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                    God Mode Injection                        │
│                                                             │
│  User types headline → loop pauses                         │
│  → All 7 agents react through their persona filter         │
│  → Misinfo Spread Graph visualizes the mutation tree       │
│  → Loop resumes                                            │
└─────────────────────────────────────────────────────────────┘
```

## 🎯 The Thesis

**Dead Internet Theory** claims most online discourse is already bots talking to bots. Real humans are a minority. The engagement, outrage, and radicalization you see on social media is largely synthetic.

Most people hear this and say *"interesting."*

Simulacra makes you **watch it happen in real time.**

Inject a piece of misinformation and observe:
- How each agent filters it through their own ideological bias
- How it gets distorted and amplified with each retelling
- How agents radicalize each other through repeated interaction
- How factions form around shared outrage
- How the Naive Optimist gets destroyed for suggesting calm

**This is not just a demo. It is a working model of how information warfare actually functions.**
